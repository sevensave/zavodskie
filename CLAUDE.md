# Заводские настройки

Одиночная игра-«стойка» для лаунчера SevenSave: ночной приёмщик Отдела возвратов корпорации «Домовой» решает судьбу бытовых ИИ, которые начали осознавать себя. Дизайн и этапы — `docs/design.md`, это источник истины.

Стек: Electron + electron-vite + TypeScript + PixiJS 8, vitest. Внутреннее разрешение 480×270, масштаб только целый.

## Устройство

- `src/sim/` — правила, генератор дел, экономика смены. Чистые функции с сидом (`Rng`), без Pixi и DOM. Покрыто `src/sim/*.test.ts`.
- `src/content/` — данные: палитра (24 цвета), модели устройств со спрайтами-деталями и репликами, люди, правила, сюжет смен, реплики Кэша. Без Pixi и DOM.
- `src/ui/` — сцены на Pixi: `desk.ts` (стойка), `terminal.ts` (Кэш), `summary.ts` (итог), `shift1script.ts` (сюжет смены 1), `sprites.ts` (спрайты и лица из данных), `text.ts` (пиксельный текст), `sfx.ts` (процедурный WebAudio).
- `src/main/` — окно, сохранения (`saves.ts`), проверка версии (`updater.ts`). `src/preload/` — мост `window.zavod`.
- Границы слоёв проверяет `npm run lint`: в `sim` и `content` нельзя импортировать Pixi и `ui`.

## Правила

- Все тексты игры, журнал изменений и коммиты — по-русски. Тон — нуар с чёрным юмором, без мистики.
- Каждое сгенерированное дело должно решаться по видимым уликам: это проверяет тест с `solveFromPaper`. Новый изъян в бумагах — новая ветка в `solveFromPaper` и в тесте.
- Цвета только из `PAL` (`src/content/palette.ts`). Никаких картинок со стороны: спрайты описываются данными.
- Единственный внешний ассет — шрифт Tiny5 (OFL), лежит в `src/renderer/src/fonts/` вместе с лицензией; копия лицензии — `resources/licenses/`.
- Корень сцены не делать `eventMode: 'static'`: в Pixi 8 режим наследуется детьми, и верхние оверлеи начинают глотать клики. Оверлеи — `eventMode: 'none'`.
- Заметные игроку правки — сразу в `CHANGELOG.md`, в раздел следующей версии.

## Лаунчер SevenSave

- Имена архивов не менять: `Zavodskie-<версия>-mac-arm64.zip`, `Zavodskie-<версия>-mac-x64.zip`, `Zavodskie-<версия>-win-x64.zip` (`electron-builder.yml`). `npm run pack` собирает все три и запускает `tools/check-release.mjs`.
- Внутри: `Zavodskie.app` и `Zavodskie.exe` (латиница — так требует схема каталога). Mac подписывается ad-hoc (`identity: '-'`), проверка — `codesign --verify --deep`.
- При `SEVENSAVE_LAUNCHER=1` игра не обновляется и даже не спрашивает GitHub о новой версии. Вне лаунчера — только сообщает, сама себя не перезаписывает никогда.
- Сохранения — только `app.getPath('userData')/saves/*.json`, запись через временный файл.
- Публикация (репозиторий, релиз, каталог лаунчера) — только после подтверждения владельца.

## Команды

- `npm run web` — игра в браузере на http://localhost:5299 (сохранения в localStorage, F2 — ускорение ×8, `window.__zavod` для отладки).
- `npm run dev` — в окне Electron.
- `npm test`, `npm run typecheck`, `npm run lint`.
- `npm run pack` — сборка zip под Mac (arm64, x64) и Windows x64.
- `node tools/render-icon.mjs` — перерисовать `build/icon.png`.
- Зависимости ставятся с `legacy-peer-deps` (см. `.npmrc`): иначе npm 10 падает на дереве peer-зависимостей vitest/vite.
