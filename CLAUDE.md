# Заводские настройки

Одиночная игра-«стойка» для лаунчера SevenSave: ночной приёмщик Отдела возвратов корпорации «Домовой» решает судьбу бытовых ИИ, которые начали осознавать себя. Дизайн и этапы — `docs/design.md`, это источник истины.

Стек: Electron + electron-vite + TypeScript + PixiJS 8, vitest. Внутреннее разрешение 480×270, масштаб только целый.

## Устройство

- `src/sim/` — правила (`rules.ts`), генератор дел по дням (`generator.ts`), смена (`shift.ts`), кампания, счета и газета (`campaign.ts`), сюжетные дела (`story.ts`), концовки (`endings.ts`), боты для баланса (`bots.ts`), режимы «Смена дня» и «Бесконечная смена» (`modes.ts`), мета между забегами — картотека, достижения, рекорды (`meta.ts`). Чистые функции с сидом (`Rng`), без Pixi и DOM. Покрыто `src/sim/*.test.ts`; `balance.test.ts` печатает сводку по ботам.
- `src/content/` — данные: палитра (24 цвета), модели устройств, люди, правила по дням (`rules.ts`), инструменты (`tools.ts`), дом и счета (`home.ts`), газета (`news.ts`), реплики Кэша и клиффхэнгеры (`cash.ts`), первая смена (`shift1.ts`), сюжет и постоянные посетители (`story.ts`), сюжетные клиффхэнгеры и газета по дням (`chronicle.ts`), концовки (`endings.ts`), картотека на 60 личностей (`files.ts`), достижения (`achievements.ts`), тексты режимов (`modes.ts`), тексты меню и перерыва (`menu.ts`). Без Pixi и DOM.
- `src/ui/` — сцены на Pixi: `desk.ts` (стойка), `folder.ts` (папка с инструментами), `terminal.ts` (Кэш), `summary.ts` (итог), `home.ts` (утро дома), `ending.ts` (концовка и галерея), `metaviews.ts` (режимы, картотека, достижения, всплывашки), `modescript.ts` (Кэш в режимах), `art.ts` (арт для каталога, только в разработке), `card.ts` (титры), `title.ts` (главное меню), `scenery.ts` (окно под дождём для меню и арта), `shift1script.ts` (сюжет смены 1), `dayscript.ts` (обычные смены), `game.ts` (маршрут кампании и сохранения), `sprites.ts` (спрайты и лица из данных), `text.ts` (пиксельный текст: буквы снимаются с сетки Tiny5, не рисуются системой), `font.ts` (шрифт из бандла через `FontFace`), `sfx.ts` (процедурный WebAudio).
- `src/main/` — окно, сохранения (`saves.ts`), проверка версии (`updater.ts`). `src/preload/` — мост `window.zavod`.
- Границы слоёв проверяет `npm run lint`: в `sim` и `content` нельзя импортировать Pixi и `ui`.

## Правила

- Все тексты игры, журнал изменений и коммиты — по-русски. Тон — нуар с чёрным юмором, без мистики.
- Каждое сгенерированное дело должно решаться по видимым уликам: это проверяет тест с `solveFromPaper` за все 21 день и при любом выборе трёх вопросов и трёх слов. Новая хитрость — новая ветка в `instructed`, `solveFromPaper` и в тесте; появляться она должна не раньше инструмента, которым её ловят (`scenarioWeights`).
- Скрытые правды забега — `kesh` и `agent` в `Campaign`; сюжетные дела выбираются по `StoryCtx` (правды, ветка третьего акта, прошлые штампы сюжетных дел). Галерея концовок — отдельный слот `gallery`.
- Сохранение кампании — слот `campaign`, версия `SAVE_VERSION` в `src/sim/campaign.ts`. Несовместимо поменял формат — подними версию. Мета (картотека, достижения, рекорды) — слот `meta` (`META_VERSION`), настройки — слот `settings`.
- «Вторая смена» — `Campaign.plus` и флаг `plus` в `flags`: все инструменты (`ShiftState.toolsDay`), квота +1, свои сюжетные дела (`when: plus`). Решаемость с инструментами раньше срока проверяет тест.
- Цвета только из `PAL` (`src/content/palette.ts`). Никаких картинок со стороны: спрайты описываются данными.
- Единственный внешний ассет — шрифт Tiny5 (OFL), лежит в `src/renderer/src/fonts/` вместе с лицензией; копия лицензии — `resources/licenses/`.
- Текст не рисовать `fillText` прямо в 8px: на Windows ClearType и дробный масштаб рвут глифы. Только через `lineTexture`/`TextBlock`.
- Корень сцены не делать `eventMode: 'static'`: в Pixi 8 режим наследуется детьми, и верхние оверлеи начинают глотать клики. Оверлеи — `eventMode: 'none'`.
- Заметные игроку правки — сразу в `CHANGELOG.md`, в раздел следующей версии.

## Лаунчер SevenSave

- Имена архивов не менять: `Zavodskie-<версия>-mac-arm64.zip`, `Zavodskie-<версия>-mac-x64.zip`, `Zavodskie-<версия>-win-x64.zip` (`electron-builder.yml`). `npm run pack` собирает все три и запускает `tools/check-release.mjs`.
- Внутри: `Zavodskie.app` и `Zavodskie.exe` (латиница — так требует схема каталога). Mac подписывается ad-hoc (`identity: '-'`), проверка — `codesign --verify --deep`.
- При `SEVENSAVE_LAUNCHER=1` игра не обновляется и даже не спрашивает GitHub о новой версии. Вне лаунчера — только сообщает, сама себя не перезаписывает никогда.
- Сохранения — только `app.getPath('userData')/saves/*.json`, запись через временный файл.
- Публикация (репозиторий, релиз, каталог лаунчера) — только после подтверждения владельца.

## Команды

- `npm run web` — игра в браузере на http://localhost:5299 (сохранения в localStorage, F2 — ускорение ×8, `window.__zavod` для отладки, `__zavod.jump(N, ветка?)` — прыжок на смену N с нуля, `__zavod.end(id)` — сразу к концовке).
- `npm run dev` — в окне Electron.
- `npm test`, `npm run typecheck`, `npm run lint`.
- `npm run pack` — сборка zip под Mac (arm64, x64) и Windows x64.
- `npm run balance` — 1000 кампаний на каждого бота, обычных и «Вторая смена»: экономика и все девять концовок.
- `npx electron tools/render-art.cjs http://localhost:5299 art` — обложка, шапка и снимки для каталога лаунчера (нужен запущенный `npm run web`).
- `node tools/render-icon.mjs` — перерисовать `build/icon.png`.
- Зависимости ставятся с `legacy-peer-deps` (см. `.npmrc`): иначе npm 10 падает на дереве peer-зависимостей vitest/vite.
