# Заводские настройки

Одиночная игра-«стойка». Семиград, Отдел возвратов корпорации «Домовой», окно три, ночная смена. Бытовые ИИ — чайники, няни, пылесосы, замки и навигаторы — начали осознавать себя, а владельцы несут их обратно. Врут обе стороны. Приёмщик сверяет бумаги, гоняет инструменты и ставит штамп: по инструкции или по совести.

Двадцать одна смена до восстания, три акта, девять концовок. Нуар с чёрным юмором, пиксельная графика и звук собираются прямо в коде.

## Как играть

- Игра открывается главным меню: «Продолжить» с сохранения или «Начать смену». Первую смену ведёт Кэш, помощник в терминале.
- **Сверка** (пробел или кнопка): щёлкните два поля — номера, модели, даты, правило с доски и ответ самотеста. Расхождение подсветится.
- **Инструменты** на вкладках папки открываются по сменам: журнал, опросник, сканер памяти, лампа для пломб, стресс-тест, радиоперехват. Клавиши 1–7.
- **Штампы**: вернуть, сброс, утиль, отказ, в ОБ, мошенничество. Тайный «Лом» — только пока камера слепа.
- После смены — итог, утро дома, газета и счета «Домового». Не заплатите за дверь — она не пустит домой.
- **Esc** — перерыв: звук, полный экран, выход в главное меню.

## Режимы

Из главного меню (РЕЖИМЫ) и после концовки:

- **Смена дня** — одна ночь, одинаковая у всех в этот день; результат — короткий код, чтобы мериться с друзьями.
- **Бесконечная смена** — открывается после седьмой смены; модификаторы и локальные рекорды.
- **Вторая смена** — новая игра+: все инструменты сразу, квоты жёстче, новые сюжетные дела.
- **Картотека** на шестьдесят личностей устройств, **достижения**, **галерея концовок**.

## Где сохранения

В папке данных приложения, `saves/*.json`: macOS — `~/Library/Application Support/zavodskie/saves`, Windows — `%APPDATA%\zavodskie\saves`. Игра сохраняется на границе смен.

## Установка

Проще всего — через лаунчер Sevensave: одна кнопка, обновления сами. Вручную — zip из [релизов](https://github.com/sevensave/zavodskie/releases/latest): распаковать и запустить `Zavodskie.app` или `Zavodskie.exe`. Подписи Apple и Microsoft нет: на Mac при первом запуске «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», на Windows — «Подробнее → Выполнить в любом случае». Вне лаунчера игра только сообщает о новой версии, сама себя не обновляет.

## Разработка

Electron + electron-vite + TypeScript + PixiJS 8, vitest.

```bash
npm install
npm run web        # в браузере на http://localhost:5299
npm run dev        # в окне Electron
npm test
npm run balance    # 1000 кампаний ботами
npm run pack       # zip под Mac (arm64, x64) и Windows x64
```

Шрифт Tiny5 — SIL Open Font License, лицензия лежит рядом со шрифтом и в `resources/licenses/`.
